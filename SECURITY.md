# Security

Report a vulnerability in this library or in AY Inbox to team@ayinbox.com. Please do not open a public issue for it.

Include the version you use, what you found and how to reproduce it. We will answer and keep you posted while we fix it.

Never paste an API key into an issue, a log or an example. If a key has leaked, revoke it in the dashboard at https://app.ayinbox.com and create a new one.
